# 道具

## 商店道具

商店道具是指玩家升级时触发的商店中可购买的道具，商店内的道具内容配置在```ItemConfig```表格中。

![image.png](https://cgugc-video-test-1258633575.cos.ap-shanghai.myqcloud.com/wiki_picture/mK8w9image.png)

Blade：双刃剑，暴击率+0.05，近战伤害+1，最大生命-1

Bracers：冲击护腕，击退幅度+0.2

Cells：活性细胞，最大生命+3，生命回复+0.2

Colossus：残破巨像，最大生命+5，移动速度-0.25

Gloves：拳击手套，近战伤害+1.5

HeavyAmmo：大口径弹药，枪械伤害+1

IronWall：铜墙铁壁，移动速度-0.2，防御+0.2

LongSight：长程瞄具，攻击范围+50

Mag：强力磁场，拾取范围+10

NanoFix：纳米修复，生命回复+0.2

Overheat：过热核心，技能伤害+1，最大生命-1

Overload：神经超载，攻击速度+0.3，攻击力-0.15

Quick：迅捷肌腱，移动速度+0.5

Safe：安全协议，最大生命+3，攻击力-0.1

WideCollect：广域收集，拾取范围+100

### 道具配置

商店物品在此处的配置较少，且均为通用配置。

![image.png](https://cgugc-video-test-1258633575.cos.ap-shanghai.myqcloud.com/wiki_picture/pTiP8image.png)

基础配置：包括自动生成的物品ID、名称、堆叠数量等。在此处需要配置完整的物品信息，因为游戏内的商店界面会读取该处的物品信息来显示。

背包配置：商店道具是购买后自动激活对应buff，因此不选择使用和丢弃。角色死亡或对局数据清空时需要重置，因此需要选择配【可销毁】

物品标记：需要选择Item.Effectltem，该tag对应的是会对玩家生效的物品。只有有这个tag或者父tag有这个tag的道具，才会触发道具表里面的buff和技能

死亡物品掉落配置：在该玩法里玩家死亡不掉落，且有复活可能，因此选择留在背包

### 道具生效

每个道具都需要在```ItemConfig```表格中配置，以对应商店刷新组、BUFF生效等。

## 掉落道具

掉落道具是指敌人死亡时掉落的道具，需要与怪物掉落系统协同作用。

![image.png](https://cgugc-video-test-1258633575.cos.ap-shanghai.myqcloud.com/wiki_picture/tghxRimage.png)

目前工程中，掉落的道具有以下三个：

Drop_Fast：阵风，立刻增加0.5的移速，持续3秒，持续时间内重复获取会刷新时间
Drop_HpBag：急救包，立刻恢复10%最大血量
Drop_Magnet：磁铁，立刻吸附全场的金币

### 掉落道具配置

打开物品编辑器，在物品选项的空白模板中，选择“空白消耗品”作为模板创建物品；也可以根据需求，使用其他已配置完成的模板。本样例工程中的掉落道具使用的是“空白消耗品”模板。

![image.png](https://cgugc-video-test-1258633575.cos.ap-shanghai.myqcloud.com/wiki_picture/oOF4Limage.png)

创建后，即可获取该物品的ID，并自定义该掉落物的属性。掉落物品在此处的配置较少，且均为通用配置，因此以hpbag为例说明：

![image.png](https://cgugc-video-test-1258633575.cos.ap-shanghai.myqcloud.com/wiki_picture/mTOlAimage.png)

该物品不会在 UI 上显示，但会在场景中显示，因此可以不配置图标、描述等 UI 信息，但需要配置对应模型。

在当前玩法中，掉落物会在被拾取后自动使用并销毁，因此在背包配置中需要勾选“可使用”与“可销毁”。

在物品标记中，需要选择生效物品下的 AutoRemove Tag。

### 配置掉落道具BUFF

本样例工程中的掉落道具 Buff 使用的是“空模板”。

打开技能编辑器，在 Buff 选项的模板列表中，选择以“空模板”为基础创建；也可以根据实际需求，使用其他已配置完成的模板。

![image.png](https://cgugc-video-test-1258633575.cos.ap-shanghai.myqcloud.com/wiki_picture/PS2Nsimage.png)

创建完成后，即可自定义该 Buff 的效果，Buff 的具体效果主要由触发效果决定。

![image.png](https://cgugc-video-test-1258633575.cos.ap-shanghai.myqcloud.com/wiki_picture/5m3uyimage.png)

### 配置表

掉落道具共有三种，均与其他道具一起配置在```ItemConfig```表格中。创建完成对应的道具与 Buff 后，在表格中进行关联配置即可生效。

![image.png](https://cgugc-video-test-1258633575.cos.ap-shanghai.myqcloud.com/wiki_picture/nYc2himage.png)

### 掉落道具悬浮动画配置

掉落道具分为 Coin 和其他掉落物两种，其中 Coin 对应一个特殊的 coin actor，其他掉落物则使用通用 wrapper。

Coin 使用 BP_Coin 蓝图配置，路径为 Asset/Blueprint/Interactable/BP_Coin。
其他掉落物使用 wrapper，路径为 Asset/Wrapper/CustomWrapper。

主要配置项：Start Location 表示起始位置，End Location 表示结束位置。用起始位置和结束位置的差值来决定悬浮幅度，例如图中所示即代表向上浮动60单位。

![image.png](https://cgugc-video-test-1258633575.cos.ap-shanghai.myqcloud.com/wiki_picture/V1y9wimage.png)

EasingType：缓动类型

![image.png](https://cgugc-video-test-1258633575.cos.ap-shanghai.myqcloud.com/wiki_picture/ir0mIimage.png)

|类型|运动感觉|
|-|-|
|Linear|匀速|
|Quad|轻微缓动|
|Cubic|明显缓动|
|Quart|强缓动|
|Quint|极强缓动|
|Sine|非常自然|
|Expo|爆发式|
|Circ|圆弧|
|Elastic|弹簧|
|Back|回拉|
|Bounce|弹跳|

Duration：动画时长，这里的时长指的是单向时间，因此如图中配置为2，则一次完整的悬浮往返就是4s。
EnableTween = true：表示启用该动画效果。

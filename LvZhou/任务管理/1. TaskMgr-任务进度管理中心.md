# 📋 TaskMgr.lua — 任务进度管理中心

> 负责统一管理任务进度更新，封装了组件获取和 GM 调用。

## 代码

```lua
-- TaskMgr.lua — 任务进度管理中心
-- 外部调用：
--   TaskMgr.AddLevelProgress("爬塔", 1)       -- 成长型进度+1
--   TaskMgr.AddActiveProgress("每日抽奖", 1)   -- 活跃型进度+1

local TaskMgr = {}

-- 内部：获取组件和全局Actor，带nil保护
local function GetTaskComponents()
    local PC = UGCGameSystem.GetLocalPlayerController()
    if not PC then return nil, nil end
    local Component = UGCGamePartSystem.GetGamePartPlayerComponent("TaskManager", PC, "Task")
    local GM = UGCGamePartSystem.GetGamePartGlobalActor("TaskManager")
    return Component, GM, PC
end

--- 成长型任务进度加值
---@param TaskLineName string 任务线名称
---@param AddValue     number 加多少（默认1）
---@param LevelIndex   number 阶段索引（默认1）
---@param TaskIndex    number 任务索引（默认1）
function TaskMgr.AddLevelProgress(TaskLineName, AddValue, LevelIndex, TaskIndex)
    local Component, GM, PC = GetTaskComponents()
    if not Component or not GM then return end

    LevelIndex = LevelIndex or 1
    TaskIndex = TaskIndex or 1
    local Current = Component:GetLevelTaskProgress(TaskLineName, LevelIndex, TaskIndex)

    GM:UpdateTaskProgress({
        TaskLineName = TaskLineName,
        PercentTaskIndex = 0,
        LevelTaskLevelIndex = LevelIndex,
        LevelTaskIndex = TaskIndex,
    }, PC, Current + (AddValue or 1))
end

--- 活跃型任务进度加值
---@param TaskLineName string 任务线名称
---@param AddValue     number 加多少（默认1）
---@param TaskIndex    number 任务索引（默认1）
function TaskMgr.AddActiveProgress(TaskLineName, AddValue, TaskIndex)
    local Component, GM, PC = GetTaskComponents()
    if not Component or not GM then return end

    TaskIndex = TaskIndex or 1
    local Current = Component:GetPercentTaskProgress(TaskLineName, TaskIndex)

    GM:UpdateTaskProgress({
        TaskLineName = TaskLineName,
        PercentTaskIndex = TaskIndex,
        LevelTaskLevelIndex = 0,
        LevelTaskIndex = 0,
    }, PC, Current + (AddValue or 1))
end

return TaskMgr
```

## 枚举配置（推荐）

避免到处写死字符串，建一个 `TaskDef.lua` 集中管理：

```lua
-- TaskDef.lua — 任务定义，所有任务线名称和任务ID写在这里
local TaskDef = {
    --- 任务线名称（对应 GP_TaskManager 配的【任务线名称】）
    TaskLine = {
        DailyLottery    = "每日抽奖",       -- 活跃型
        TowerClimbing   = "爬塔",          -- 成长型
        LevelExperience = "人物等级经验",   -- ??型（待定）
    },

    --- 任务ID（对应 GP_TaskManager 配的【任务ID】）
    TaskID = {
        DailyLottery      = 1001,    -- 每日抽奖任务
        TowerClimbing_L1  = 2001,    -- 爬塔第1阶段第1个
        TowerClimbing_L2  = 2002,    -- 爬塔第1阶段第2个
    },
}
return TaskDef
```

然后使用：

```lua
local TaskDef = require("TaskDef")

-- 不用再写"每日抽奖"字符串了
TaskMgr.AddActiveProgress(TaskDef.TaskLine.DailyLottery, 1)
TaskMgr.AddLevelProgress(TaskDef.TaskLine.TowerClimbing, 1)

-- 获取进度和目标
local GM = UGCGamePartSystem.GetGamePartGlobalActor("TaskManager")
local Current = Component:GetPercentTaskProgress(TaskDef.TaskLine.DailyLottery, 1)
local Target = GM:GetTaskTarget(TaskDef.TaskID.DailyLottery)
```

### 或者干脆写进 TaskMgr 里

如果你不想多一个文件，直接加在 `TaskMgr.lua` 顶部也行：

```lua
local TaskMgr = {}

--- 任务线定义
TaskMgr.TaskLine = {
    DailyLottery  = "每日抽奖",
    TowerClimbing = "爬塔",
}

--- 任务ID定义
TaskMgr.TaskID = {
    DailyLottery      = 1001,
    TowerClimbing_L1  = 2001,
}
```

调用：

```lua
TaskMgr.AddActiveProgress(TaskMgr.TaskLine.DailyLottery, 1)
```

## 阶段索引 vs 任务索引

### 成长型任务线（LevelTask）

```
任务线(TaskLine) ── 阶段(Level)1 ── 任务(Task)1
                    │               └─ 任务(Task)2
                    │
                    ├── 阶段(Level)2 ── 任务(Task)1
                    │                   └─ 任务(Task)2
                    │
                    └── 阶段(Level)3 ── 任务(Task)1
                                        └─ 任务(Task)2
```

| 参数           | 说明                     |       示例       |
| :----------- | :--------------------- | :------------: |
| `LevelIndex` | **阶段索引** — 选择第几个阶段/等级  |   `1` = 第1阶段   |
| `TaskIndex`  | **任务索引** — 选中阶段里的第几个任务 | `2` = 该阶段第2个任务 |

> AddLevelProgress("爬塔", 1, 1, 2) = "爬塔"任务线 → 第1阶段 → 第2个任务进度+1

### 活跃型任务线（PercentTask）

```
任务线(TaskLine) ── 任务(Task)1
                    ├── 任务(Task)2
                    └── 任务(Task)3
```

活跃型**没有阶段**，只有 `TaskIndex` 表示任务在任务线里的位置。

### 对应结构体 `FUGCTaskIndex`

| 字段 | 对应参数 | 说明 |
|:----|:--------|:----|
| `TaskLineName` | 任务线名称 |  |
| `PercentTaskIndex` | (活跃型) 任务索引 | 活跃型用，成长型填 `0` |
| `LevelTaskLevelIndex` | `LevelIndex` 阶段索引 | 成长型用，活跃型填 `0` |
| `LevelTaskIndex` | `TaskIndex` 任务索引 | 成长型用，活跃型填 `0` |

## 说明

| 函数 | 类型 | 对应组件方法 |
|------|------|-------------|
| `AddLevelProgress` | 成长型 | `GetLevelTaskProgress` + `UpdateTaskProgress` |
| `AddActiveProgress` | 活跃型 | `GetPercentTaskProgress` + `UpdateTaskProgress` |

- 使用 `GamePart` 系统：PlayerComponent = `"TaskManager"` 下的 `"Task"` 组件
- GlobalActor = `GamePartGlobalActor("TaskManager")`
- 带 nil 保护，组件不存在时静默返回

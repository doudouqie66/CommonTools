# 我的笔记

## Buff 生效期间反转玩家移动输入

### 需求

玩家正常状态下保持默认移动；获得指定 Buff 后，将左摇杆的前后、左右输入全部反转；Buff 结束或被移除后恢复正常移动。

项目中的“移动反向”事件使用 `DeBuff04`：

```lua
L_Enum.Name_Event.ReverseMove = "移动反向"
L_Enum.Name_BuffPath.Debuff04 = RootPath .. "Asset/Blueprint/Prefabs/Buffs/DeBuff04.DeBuff04_C"
```

### 实现思路

1. 在本地玩家 Pawn 上监听以下两个移动轴：
   - `Input.Move.MoveRight`：左右移动。
   - `Input.Move.MoveForward`：前后移动。
2. 平时不消耗输入，由系统执行默认移动。
3. Buff 生效时开启反向移动开关，并消耗系统原始移动输入。
4. 输入回调根据镜头的水平朝向计算前、右方向，通过 `AddMovementInput` 添加负轴值。
5. Buff 移除时关闭开关并停止消耗输入，恢复系统默认移动。

### Pawn 代码

文件：`Script/Blueprint/UGCPlayerPawn.lua`

```lua
--[[----------------------初始化玩家Pawn------------------------]]
function UGCPlayerPawn:ReceiveBeginPlay()
    UGCPlayerPawn.SuperClass.ReceiveBeginPlay(self)

    if not UGCGameSystem.IsServer() and UGCGameSystem.GetLocalPlayerPawn() == self then
        self.Local_Player_Controller = UGCGameSystem.GetPlayerControllerByPlayerPawn(self)  -- 本地玩家控制器
        self.Move_Right_Input_Handle = UGCInputSystem.BindInputMapping(self, "Input.Move.MoveRight", ETriggerEvent.Triggered, self.ReverseMoveRightInput)  -- 左右移动输入绑定
        self.Move_Forward_Input_Handle = UGCInputSystem.BindInputMapping(self, "Input.Move.MoveForward", ETriggerEvent.Triggered, self.ReverseMoveForwardInput)  -- 前后移动输入绑定
        self:SetReverseMoveEnabled(false)
    end
end

--[[----------------------设置反向移动状态------------------------]]
function UGCPlayerPawn:SetReverseMoveEnabled(Is_Enabled)
    self.Is_Reverse_Move_Enabled = Is_Enabled  -- 是否启用反向移动
    UGCInputSystem.SetBindingConsumeInput(self, self.Move_Right_Input_Handle, Is_Enabled)
    UGCInputSystem.SetBindingConsumeInput(self, self.Move_Forward_Input_Handle, Is_Enabled)
end

--[[----------------------反转左右移动输入------------------------]]
function UGCPlayerPawn:ReverseMoveRightInput(Input_Value)
    if not self.Is_Reverse_Move_Enabled then
        return
    end

    local Control_Rotation = self.Local_Player_Controller:GetControlRotation()  -- 镜头控制旋转
    local Move_Rotation = KismetMathLibrary.MakeRotator(0, 0, Control_Rotation.Yaw)  -- 水平移动旋转
    local Move_Direction = KismetMathLibrary.GetRightVector(Move_Rotation)  -- 镜头右方向
    self:AddMovementInput(Move_Direction, -Input_Value, false)
end

--[[----------------------反转前后移动输入------------------------]]
function UGCPlayerPawn:ReverseMoveForwardInput(Input_Value)
    if not self.Is_Reverse_Move_Enabled then
        return
    end

    local Control_Rotation = self.Local_Player_Controller:GetControlRotation()  -- 镜头控制旋转
    local Move_Rotation = KismetMathLibrary.MakeRotator(0, 0, Control_Rotation.Yaw)  -- 水平移动旋转
    local Move_Direction = KismetMathLibrary.GetForwardVector(Move_Rotation)  -- 镜头前方向
    self:AddMovementInput(Move_Direction, -Input_Value, false)
end
```

### Buff 代码

文件：`Script/Blueprint/Prefabs/Buffs/DeBuff04.lua`

```lua
--[[----------------------Buff挂载时开启反向移动------------------------]]
function DeBuff04:OnApply_BP(OwnerActor)
    if not self:HasAuthority() and self:IsAutonomous(true) then
        OwnerActor:SetReverseMoveEnabled(true)
    end
end

--[[----------------------Buff移除时关闭反向移动------------------------]]
function DeBuff04:OnUnApply_BP(OwnerActor, Reason)
    if not self:HasAuthority() and self:IsAutonomous(true) then
        OwnerActor:SetReverseMoveEnabled(false)
    end
end
```

### 关键 API

- `UGCInputSystem.BindInputMapping`：监听输入 Tag。
- `UGCInputSystem.SetBindingConsumeInput`：控制绑定是否拦截后续默认输入。
- `APawn:AddMovementInput`：向 Pawn 添加指定世界方向的移动输入；负数代表反方向。
- `KismetMathLibrary.GetForwardVector`：根据旋转取得前方向。
- `KismetMathLibrary.GetRightVector`：根据旋转取得右方向。
- `PersistEffectBuff:OnApply_BP`：Buff 挂载回调。
- `PersistEffectBuff:OnUnApply_BP`：Buff 移除回调。
- `PersistEffectBuff:IsAutonomous(true)`：判断该 Buff 是否属于本机主控玩家。

### 踩坑记录

不要在消耗原输入后，再用 `InjectInputMapping` 向同一个移动 Tag 注入反向值。该绑定可能再次拦截脚本注入的输入，最终表现为拖动摇杆时角色完全不动。

稳定做法是：Buff 生效时消耗原始输入，然后直接调用 `AddMovementInput` 添加反方向移动。

另外，移动输入属于客户端操作，因此 Buff 中只应在客户端且目标是本机主控玩家时切换开关：

```lua
if not self:HasAuthority() and self:IsAutonomous(true) then
    -- 修改本地输入状态
end
```

## Buff08 全体飞行实现

### 需求

玩家获得 `Buff08` 后进入飞行状态：

- 左摇杆继续控制水平移动。
- 独立按钮控制上升、下降。
- Buff 结束后退出飞行并恢复原始飞行速度。
- 飞行速度应低于正常步行速度，避免切换飞行时突然加速。

### 相关文件

- `Asset/Blueprint/Prefabs/Buffs/Buff08.uasset`
- `Script/Blueprint/Prefabs/Buffs/Buff08.lua`
- `Asset/Blueprint/UI/MainUI.uasset`
- `Script/Blueprint/UI/MainUI.lua`

### 飞行状态实现

角色移动模式数值：

- `5`：飞行模式。
- `3`：下落模式。

Buff 生效时，服务端进入 `PawnState.Movement.Flying` 动态状态并将移动模式切换为飞行；Buff 移除时离开动态状态并切回下落模式。

```lua
local Fly_Movement_Mode = 5 -- 飞行移动模式
local Falling_Movement_Mode = 3 -- 下落移动模式
local Fly_State_Tag = "PawnState.Movement.Flying" -- 飞行状态标签
local Fly_Max_Speed = 450 -- 飞行最大速度

--[[----------------------Buff挂载时开启飞行------------------------]]
function Buff08:OnApply_BP(OwnerActor)
    self.Original_Fly_Max_Speed = OwnerActor.CharacterMovement.MaxFlySpeed -- 原始飞行最大速度
    OwnerActor.CharacterMovement.MaxFlySpeed = Fly_Max_Speed

    if self:HasAuthority() then
        self.Has_Entered_Fly_State = UGCPersistEffectSystem.EnterDynamicState(OwnerActor, Fly_State_Tag) -- 是否成功进入飞行状态
        OwnerActor.CharacterMovement:SetMovementMode(Fly_Movement_Mode, 0)
    elseif self:IsAutonomous(true) then
        local Player_Controller = UGCGameSystem.GetLocalPlayerController() -- 本地玩家控制器
        if Player_Controller.MainUI_BP then
            Player_Controller.MainUI_BP:SetFlyControlsEnabled(true)
        end
    end
end

--[[----------------------Buff移除时关闭飞行------------------------]]
function Buff08:OnUnApply_BP(OwnerActor, Reason)
    OwnerActor.CharacterMovement.MaxFlySpeed = self.Original_Fly_Max_Speed

    if self:HasAuthority() then
        if self.Has_Entered_Fly_State then
            UGCPersistEffectSystem.LeaveDynamicState(OwnerActor, Fly_State_Tag)
        end
        if OwnerActor.CharacterMovement.MovementMode == Fly_Movement_Mode then
            OwnerActor.CharacterMovement:SetMovementMode(Falling_Movement_Mode, 0)
        end
    elseif self:IsAutonomous(true) then
        local Player_Controller = UGCGameSystem.GetLocalPlayerController() -- 本地玩家控制器
        if Player_Controller.MainUI_BP then
            Player_Controller.MainUI_BP:SetFlyControlsEnabled(false)
        end
    end
end
```

`MaxFlySpeed` 要在服务端和本地主控客户端都设置。只在服务端修改时，本地移动预测仍可能采用原来的超高速度，产生频繁拉回或速度表现异常。

### 上升和下降按钮

飞行模式下，系统原有的跳跃、下蹲按钮无法正常按下，因此不复用原生按钮。在 `MainUI` 中使用两个独立按钮：

- `Button_87`：上升。
- `Button_263`：下降。

按钮使用 `OnPressed` 和 `OnReleased`，不能使用单次 `OnClicked`。按住时保存竖直输入值，由 UI 的 `Tick` 每帧调用 `AddMovementInput`；松开时将输入清零。

```lua
local Fly_Vertical_Input_Scale = 0.3 -- 飞行升降速度比例

--[[----------------------刷新事件秒数显示------------------------]]
function MainUI:Tick(MyGeometry, InDeltaTime)
    local GameState = UGCGameSystem.GameState
    self.TextBlock_134:SetText(tostring(GameState.EventElapsed or 0))
    if self.Fly_Vertical_Input_Value ~= 0 then
        UGCGameSystem.GetLocalPlayerPawn():AddMovementInput(Vector.New(0, 0, 1),
            self.Fly_Vertical_Input_Value, false)
    end
end

--[[----------------------按下上升按钮------------------------]]
function MainUI:Button_87_OnPressed()
    self.Fly_Vertical_Input_Value = Fly_Vertical_Input_Scale
end

--[[----------------------松开上升按钮------------------------]]
function MainUI:Button_87_OnReleased()
    if self.Fly_Vertical_Input_Value > 0 then
        self.Fly_Vertical_Input_Value = 0
    end
end

--[[----------------------按下下降按钮------------------------]]
function MainUI:Button_263_OnPressed()
    self.Fly_Vertical_Input_Value = -Fly_Vertical_Input_Scale
end

--[[----------------------松开下降按钮------------------------]]
function MainUI:Button_263_OnReleased()
    if self.Fly_Vertical_Input_Value < 0 then
        self.Fly_Vertical_Input_Value = 0
    end
end
```

Buff 生效时显示并启用两个按钮，结束时隐藏按钮，同时清除竖直输入，避免松开事件没有触发而持续升降。

### 速度异常排查

角色移动组件的实际默认值为：

- `MaxWalkSpeed = 600`
- `MaxFlySpeed = 60000`
- `BrakingDecelerationFlying = 0`

因此，调用 `SetMovementMode(5, 0)` 后会立刻改用 `MaxFlySpeed`，速度上限从 `600` 变为 `60000`，这才是 Buff08 开启时突然加速的原因。最终在 Buff08 期间将 `MaxFlySpeed` 临时限制为 `450`，结束后恢复原值。

`Fly_Vertical_Input_Scale = 0.3` 只会降低升降输入和加速度，不会限制角色最终速度；真正的速度上限必须通过 `MaxFlySpeed` 控制。

### Buff05 与 Buff08 的区别

`Buff08` 资产本身只有粒子和屏幕特效，没有修改 `UGCGeneralMoveSpeedScale`。

`Buff05（加速药水）` 的第一个 Buff 效果配置为：

- 属性：`UGCGeneralMoveSpeedScale`
- 运算：加法
- 数值：`0.6`
- 生效结果：`1.0 → 1.6`

运行日志确认 Buff05 持续两秒后会正常恢复：

- Buff05 生效：`UGCGeneralMoveSpeedScale 1.0 → 1.6`
- Buff05 结束：`UGCGeneralMoveSpeedScale 1.6 → 1.0`
- Buff08 在约 13 秒后才开始，故飞行加速并不是 Buff05 残留。

### 关键结论

1. 飞行需要同时进入飞行动态状态并设置移动模式 `5`。
2. 原生跳跃、下蹲按钮在飞行状态下不适合作为升降控制，应使用独立 UI 按钮。
3. 持续移动使用 `OnPressed + OnReleased + Tick`，不能只响应 `OnClicked`。
4. 输入比例只影响加速度，`MaxFlySpeed` 才决定飞行最终速度。
5. 临时修改移动组件参数时必须保存原值，并在 Buff 移除时恢复。

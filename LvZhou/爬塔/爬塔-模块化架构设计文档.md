# 爬塔项目 — 模块化架构与规范化流程设计文档（修订版v2）

> 项目：和平精英绿洲启元 UGC
> 类型：多人合作 · 躲避跑酷 · 螺旋爬塔
> 日期：2025-07-14

---

## 一、核心玩法概要

### 1.1 游戏定位

- **地图结构**：螺旋上升的环形塔，每圈（层）有怪物巡逻 + 一个安全区平台
- **核心玩法**：玩家从塔底出发，沿螺旋路径向上攀爬，躲避不可击杀的怪物
- **失败条件**：被怪物碰到 → 回到起点/塔底
- **胜利目标**：到达塔顶（先做 20 层测试）
- **工具系统**：喷射钩爪、喷气背包（有耐久，不足以到顶，需要策略使用）
- **近怪反馈**：怪物靠近时 → 屏幕剧烈颤抖 + 滤镜频闪
- **节点模式**：塔顶到达后 → 奖杯+1 → 传送回起点 → 可重复挑战

### 1.2 怪物机制（核心：不可击杀）

- 每层有怪物巡逻
- 怪物出现时，玩家需躲进**安全区平台**内
- 被怪物吃掉 → 回到起点（重置爬塔进度）
- 怪物不可被攻击/击杀
- 道具**不可在安全区内使用**（弹板、粑粑、炸弹、击飞手掌等）

### 1.3 定时事件（循环）

| 触发时间 | 事件 | 前置提醒 | 事件持续 | 效果 |
|:--|:--|:--|:--|:--|
| 60s | 移动减速 | 10s 倒计时 | 10s | 全体移速降低 |
| 120s | 黑夜 | 10s 倒计时 | 10s | 视野变暗 |
| 300s | 移动加速 | 10s 倒计时 | 15s | 全体移速提升 |
| 450s | 移动反方向 | 10s 倒计时 | 10s | 操作方向反转 |
| 600s | 黑夜 | 5s 倒计时 | 5s | 视野变暗（短促） |
| → | **循环重复** | — | — | — |

### 1.4 密道系统

- 每个房间刷新随机 4 位数密码
- 输入正确密码可打开密道（快速登顶捷径）
- 密道开启后 **20s 关闭**
- 密道出去后还有 **6 圈** 到达终点

### 2.2 8 个 Manager 模块

| 模块 | 职责 | 关键差异（vs v1） |
|:--|:--|:--|
| **RingManager** | 环形层生成、螺旋路径、安全区平台 | 从"楼层"改为"环形层"，每圈一个安全区 |
| **MonsterManager** | 怪物巡逻路径、追捕逻辑、近怪反馈 | **怪物不可击杀**，新增靠近反馈系统 |
| **EventManager** | 定时事件循环（减速/黑夜/加速/反向） | 从"随机事件"改为**固定时间轴循环事件** |
| **ItemManager** | 道具库存、工具耐久度、使用限制 | 新增耐久度系统、安全区禁用规则 |
| **PlayerManager** | 玩家状态、复活重置、近怪效果 | 被碰=回起点，新增镜头颤抖+滤镜 |
| **ShopManager** | 金币系统、在线时长奖励、周卡 | **全新模块**——经济系统 |
| **SecretManager** | 密码生成、密道开关、传送 | **全新模块**——密道系统 |
| **ProgressManager** | 层数追踪、奖杯计数、统计 | 新增奖杯系统（通关次数） |

## 四、各 Manager 详细设计

### 4.1 RingManager — 环形层 & 安全区

| 项 | 说明 |
|:--|:--|
| **职责** | 管理螺旋上升的环形层，每圈生成怪物巡逻路径和安全区平台 |
| **核心接口** | `Init(totalRings)`、`GetCurrentRing()`、`EnterSafeZone(playerKey)`、`LeaveSafeZone(playerKey)`、`IsInSafeZone(playerKey)`、`OnReachedTop(playerKey)` |
| **发出事件** | `Tower_RingEntered`、`Tower_ReachedTop` |
| **配置** | 总层数（先20层）、每圈高度差、安全区位置、螺旋角度 |

### 4.2 MonsterManager — 怪物巡逻 & 追捕

| 项 | 说明 |
|:--|:--|
| **职责** | 怪物沿环形路径巡逻，检测玩家距离，触发反馈和捕获 |
| **核心接口** | `Init(ringNum)`、`StartPatrol(ringNum)`、`CheckPlayerDistance(playerKey)`、`CaughtPlayer(playerKey)` |
| **发出事件** | `Tower_MonsterClose`、`Tower_MonsterCaught` |
| **关键逻辑** | 怪物**不可击杀**，靠近时根据距离计算屏幕颤抖强度（0-1）和滤镜频闪频率 |
| **配置** | 怪物巡逻速度、检测半径、颤抖强度曲线、每圈怪物数量 |

### 4.3 EventManager — 定时事件循环

| 项 | 说明 |
|:--|:--|
| **职责** | 按固定时间轴触发全局事件，包含前置倒计时和事件持续时间 |
| **核心接口** | `StartLoop()`、`GetCurrentEvent()`、`GetNextEventTime()` |
| **发出事件** | `Tower_EventWarning`、`Tower_EventActive`、`Tower_EventEnded` |
| **事件循环** | 减速(60s) → 黑夜(120s) → 加速(300s) → 反向(450s) → 黑夜(600s) → **循环** |
| **配置** | DataTable：事件时间轴（可配） |

### 4.4 ItemManager — 道具 & 耐久

| 项 | 说明 |
|:--|:--|
| **职责** | 玩家道具库存管理，工具耐久度系统，使用限制检查 |
| **核心接口** | `AddItem(playerKey, itemId)`、`UseItem(playerKey, itemId)`、`GetDurability(itemId)`、`OnDurabilityDepleted(itemId)`、`CanUseInSafeZone(itemId)` |
| **发出事件** | `Tower_ItemUsed`、`Tower_ItemBroken` |
| **道具分类** | **工具类**（耐久）：喷射钩爪、火箭背包、魔法飞毯；**消耗类**：加速药水、跳高药水、无敌药水；**恶搞类**：击飞手掌、大力巴掌、冰冻锤、弹板、粑粑、炸弹；**功能类**：返回、密道密码纸条 |
| **安全区禁用** | 弹板、粑粑、炸弹、击飞手掌、大力巴掌、冰冻锤 — **不可在安全区内使用** |
| **耐久机制** | 钩爪/背包耐久不足以到顶（约到9/10层损坏），需要策略分配使用 |

### 4.5 PlayerManager — 玩家状态 & 反馈

| 项 | 说明 |
|:--|:--|
| **职责** | 管理玩家状态（存活/被抓），近怪感官反馈，复活重置 |
| **核心接口** | `OnCaught(playerKey)`、`ResetToStart(playerKey)`、`SetCameraShake(playerKey, intensity)`、`SetScreenFilter(playerKey, enabled)`、`GetPlayerState(playerKey)` |
| **发出事件** | —（主要是监听其他事件并更新状态） |
| **关键逻辑** | 被怪物碰到 → 回起点（所有爬塔进度重置）；近怪 → 摄像机颤抖（幅度随距离增加）+ 滤镜频闪；安全区内 → 解除颤抖/频闪 |

### 4.6 ShopManager — 经济系统（全新）

| 项 | 说明 |
|:--|:--|
| **职责** | 金币赚取、商店购买、在线时长奖励、周卡系统 |
| **核心接口** | `GetCoins(playerKey)`、`AddCoins(playerKey, amount)`、`SpendCoins(playerKey, amount)`、`PurchaseItem(playerKey, shopItemId)`、`GetOnlineTimeReward(playerKey, elapsed)`、`ActivateWeeklyCard(playerKey)`、`IsWeeklyCardActive(playerKey)` |
| **发出事件** | `Tower_CoinChanged`、`Tower_ItemPurchased` |
| **金币获取** | 跑步机锻炼（每3秒+2金币），周卡用户每3秒+3金币 |
| **在线时长奖励** | 360s→击飞手掌(单局)，720s→香蕉皮，1080s→地雷，1560s→勾爪，2100s→喷气背包 |
| **周卡特权** | 跑步1.5倍金币、火箭背包、喷射钩爪、金币+3000、炸弹+5、弹板+5、粑粑+5；售价48绿洲币（原价68），限时88天 |
| **金币商店** | 见下方道具价格表 |

### 4.7 SecretManager — 密道系统（全新）

| 项 | 说明 |
|:--|:--|
| **职责** | 每个房间生成随机4位数密码，验证密码，管理密道开关和传送 |
| **核心接口** | `GenerateCode(ringNum)`、`VerifyCode(playerKey, input)`、`OpenPassage(ringNum)`、`TeleportThrough(playerKey)`、`ClosePassage(ringNum)` |
| **发出事件** | `Tower_SecretCode`、`Tower_SecretOpened` |
| **关键逻辑** | 密码随机生成（每局每个房间不同）；密道开启后**20s自动关闭**；密道出去后还有6圈到顶；玩家需要购买密码纸条才能知道密码 |

### 4.8 ProgressManager — 奖杯 & 统计

| 项 | 说明 |
|:--|:--|
| **职责** | 追踪当前爬塔层数、通关次数（奖杯）、数据统计 |
| **核心接口** | `GetCurrentRing()`、`AddTrophy(playerKey)`、`GetTrophyCount(playerKey)`、`GetRunSummary()` |
| **发出事件** | `Tower_TrophyChanged` |
| **奖杯机制** | 到达塔顶点击奖杯 → 奖杯+1 → 传送回起点 |

## 六、核心事件时间轴

```
时间轴（秒）:
0s     60s    120s         300s         450s         600s    660s    720s...
│      │      │            │            │            │      │      │
│ 减速 │ 黑夜 │    加速    │   反向     │  黑夜      │ 减速 │ 黑夜 │ ...
│10+10s│10+10s│  10+15s    │  10+10s    │  5+5s      │      │      │
└──────┴──────┴────────────┴────────────┴────────────┴──────┴──────┘
                                                          ← 循环 →
```

每个事件分两阶段：
1. **倒计时阶段**（Warning）：UI 显示即将发生的事件 + 倒计时
2. **生效阶段**（Active）：事件效果持续 N 秒

## 七、规范化开发流程

### 7.1 Git 分支策略

```
main ── 稳定版本
  │
  └─ dev ── 开发主分支
       │
       ├─ feat/ring-system         ← 环形层 & 安全区
       ├─ feat/monster-system      ← 怪物巡逻 & 追捕
       ├─ feat/event-system        ← 定时事件循环
       ├─ feat/item-system         ← 道具 & 耐久
       ├─ feat/player-feedback     ← 镜头颤抖 & 滤镜
       ├─ feat/shop-system         ← 经济系统
       ├─ feat/secret-passage      ← 密道系统
       └─ feat/progress-system     ← 奖杯 & 统计
```

### 7.2 开发节奏

1. **接口先行** — TowerDefines 定义事件常量
2. **配 DataTable** — 商店价格、道具属性、事件时间轴、怪物配置
3. **实现 Manager** — 纯 Lua 逻辑
4. **手动测试** — 走通核心路径
5. **接 UI** — 监听事件更新显示

### 7.3 配置分离

```
✅ DataTable：
  TowerConfig_Rings       ← 每圈高度、怪物数量、安全区位置
  TowerConfig_Monsters    ← 怪物速度、检测半径
  TowerConfig_Events      ← 时间轴、事件参数
  TowerConfig_Items       ← 道具属性、价格、耐久、限制
  TowerConfig_Shop        ← 商店商品、在线时长奖励
  TowerConfig_Secrets     ← 密道配置

❌ 硬编码：
  if time == 60 then SpeedDown() end  ← 不要
```

## 八、实施优先级建议

| 优先级    | 模块                         | 理由              |
| :----- | :------------------------- | :-------------- |
| **P0** | TowerDefines + RingManager | 地图骨架，其他模块依赖     |
| **P0** | MonsterManager             | 核心玩法——怪物不可击杀的追捕 |
| **P0** | PlayerManager              | 被碰回起点、镜头颤抖反馈    |
| **P1** | EventManager               | 定时事件增加变化性       |
| **P1** | ItemManager                | 道具系统核心逻辑        |
| **P2** | ShopManager                | 经济系统，边界功能       |
| **P2** | SecretManager              | 密道系统，锦上添花       |
| **P2** | ProgressManager            | 奖杯统计，收尾功能       |

**MVP 建议**：先实现 P0 三大模块 → 可玩的爬塔原型（环形层 + 怪物追捕 + 被碰回起点）→ 再逐步添加事件、道具、商店、密道。

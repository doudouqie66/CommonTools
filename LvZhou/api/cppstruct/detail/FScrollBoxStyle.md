# FScrollBoxStyle

Represents the appearance of an SScrollBox

## Variables

| Name | Type | Description |
|------|------|-------------|
| TopShadowBrush | FSlateBrush | Brush used to draw the top shadow of a scrollbox |
| BottomShadowBrush | FSlateBrush | Brush used to draw the bottom shadow of a scrollbox |
| LeftShadowBrush | FSlateBrush | Brush used to draw the left shadow of a scrollbox |
| RightShadowBrush | FSlateBrush | Brush used to draw the right shadow of a scrollbox |

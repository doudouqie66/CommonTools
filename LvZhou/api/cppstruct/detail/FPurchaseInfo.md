# FPurchaseInfo

Purchase information structure

## Variables

| Name | Type | Description |
|------|------|-------------|
| Identifier | FString | Unique identifier for the purchase |
| DisplayName | FString | Name displayable to the user |
| DisplayDescription | FString | Description displayable to the user |
| DisplayPrice | FString | Price displayable to the user |

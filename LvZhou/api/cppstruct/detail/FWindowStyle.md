# FWindowStyle

Represents the appearance of an SWindow

## Variables

| Name | Type | Description |
|------|------|-------------|
| MinimizeButtonStyle | FButtonStyle | Style used to draw the window minimize button |
| MaximizeButtonStyle | FButtonStyle | Style used to draw the window maximize button |
| RestoreButtonStyle | FButtonStyle | Style used to draw the window restore button |
| CloseButtonStyle | FButtonStyle | Style used to draw the window close button |
| TitleTextStyle | FTextBlockStyle | Style used to draw the window title text |
| ActiveTitleBrush | FSlateBrush | Brush used to draw the window title area when the window is active |
| InactiveTitleBrush | FSlateBrush | Brush used to draw the window title area when the window is inactive |
| FlashTitleBrush | FSlateBrush | Brush used to draw the window title area when the window is flashing |
| BackgroundColor | FSlateColor | Color used to draw the window background |
| OutlineBrush | FSlateBrush | Brush used to draw the window outline |
| OutlineColor | FSlateColor | Color used to draw the window outline |
| BorderBrush | FSlateBrush | Brush used to draw the window border |
| BackgroundBrush | FSlateBrush | Brush used to draw the window background |
| ChildBackgroundBrush | FSlateBrush | Brush used to draw the background of child windows |

# FScalarParameterNameAndCurve

Structure representing an animated scalar parameter and it's associated animation curve.

## Variables

| Name | Type | Description |
|------|------|-------------|
| ParameterName | FName | The name of the scalar parameter which is being animated. |
| Index | int32 |  |
| ParameterCurve | FRichCurve | The curve which contains the animation data for the scalar parameter. |

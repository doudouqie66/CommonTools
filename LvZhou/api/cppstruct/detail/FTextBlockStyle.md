# FTextBlockStyle

Represents the appearance of an STextBlock

## Variables

| Name | Type | Description |
|------|------|-------------|
| Font | FSlateFontInfo | Font family and size to be used when displaying this text. |
| ColorAndOpacity | FSlateColor | The color and opacity of this text |
| ShadowOffset | FVector2D | How much should the shadow be offset? An offset of 0 implies no shadow. |
| ShadowColorAndOpacity | FLinearColor | The color and opacity of the shadow |
| SelectedBackgroundColor | FSlateColor | The background color of selected text |
| HighlightColor | FLinearColor | The color of highlighted text |
| HighlightShape | FSlateBrush | The shape of highlighted text |
| UnderlineBrush | FSlateBrush | The brush used to draw an underline under the text (if any) |

# FSliderStyle

Represents the appearance of an SSlider

## Variables

| Name | Type | Description |
|------|------|-------------|
| NormalBarImage | FSlateBrush | Image to use when the slider bar is in its normal state |
| DisabledBarImage | FSlateBrush | Image to use when the slider bar is in its disabled state |
| NormalThumbImage | FSlateBrush | Image to use when the slider thumb is in its normal state |
| DisabledThumbImage | FSlateBrush | Image to use when the slider thumb is in its disabled state |
| BarThickness | float |  |

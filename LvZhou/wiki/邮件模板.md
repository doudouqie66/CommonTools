# 邮件模板

邮件模板是绿洲编辑器提供的官方功能模板，可用于在UGC项目中快速搭建完整的邮件系统。该模板支持多种类型的邮件管理，具备丰富的UI交互和完善的附件领取机制，让玩家可以方便地接收、查看和管理游戏内的各类邮件。

<br>

## 功能概要

目前邮件模板具有以下功能特性：
- 支持多类型邮件分类管理（系统邮件、通知、礼包、安全邮件等）
- 邮件已读/未读状态标识
- 过期邮件自动清理机制
- 一键已读、一键删除和一键领取等批量操作
- 邮件红点提示（新邮件提醒）

邮件模板适用于以下场景：
- 系统公告与活动通知
- 游戏奖励发放与补偿
- 好友间的道具赠送
- 赛事活动奖励领取
- 账号安全提醒

### 打开邮件界面

在控件蓝图中添加一个按钮作为邮件入口，并为按钮添加以下逻辑实现打开邮件界面的效果。

![image.png](https://cgugc-video-test-1258633575.cos.ap-shanghai.myqcloud.com/wiki_picture/pGCdCimage.png)

``` lua
function MainUI:Button_81_OnClicked()
	-- 获取当前客户端的PlayerController
	local playercontroller = UGCGameSystem.GetLocalPlayerController()
	-- 加载UGCMailboxComponent类
	local mailboxclass = UGCObjectUtility.LoadClass(UGCGameSystem.GetUGCResourcesFullPath('ExtendResource/Mail/OfficialPackage/Asset/Mail/CMPT/UGCMailboxComponent.UGCMailboxComponent_C'))
	-- 获取PlayerController中的UGCMailboxComponent，并执行打开邮箱主界面
	local components = UGCActorComponentUtility.GetComponentsByClass(playercontroller, mailboxclass)
	if #components == 0 then
		ugcprint("错误：玩家控制器上没有找到 UGCMailboxComponent 组件")
		return nil;
	else
		ugcprint("找到 UGCMailboxComponent 组件，数量: " .. tostring(#components))
		local mailbox = components[1]
		mailbox:OpenMailUI()
	end
	return nil;
end
```

进入调试后，点击按钮打开邮箱主界面。

### 模拟邮件发送

> 正式发布的玩法需联系官方运营进行邮件发送

在调试游戏期间，模板会自动发送多封测试邮件，开发者可调用 [```UGCMailSystem.PIESendMail```](https://developer.gp.qq.com/api/#/searchContent/UGCMailSystem?classDetailShow=true&path=class%2Fdetail%2FOthers%2FUGCMailSystem.json&isSelect=1&apiEnc=%5B%22%E7%B1%BB%22%5D&apiLabel=UGCMailSystem&autoJump=PIESendMail) 模拟邮件发送，示例代码如下：

``` lua
function UGCPlayerController:SendMail()
		--根据PlayerController获取当前玩家的UID
    local Uid = UGCGameSystem.GetUIDByPlayerController(self)
		--获取当前服务器时间
    local CurrentTime = UGCGameSystem.GetServerTimeSec()
		--发送邮件, 仅PIE环境有效
    UGCMailSystem.PIESendMail(Uid, "示例邮件", "这封邮件将在2分钟后过期。", CurrentTime + 2*60, {[1001]=1})
end
```

## 常见问题解答（FAQ）

### Q1：邮件最多能保存多少封？

**A**：默认最大容量为100封。当达到上限后，新邮件将自动清理过期时间最早的邮件。

---

### Q2：邮件过期后还能查看吗？

**A**：过期邮件会自动从列表中移除，无法查看。建议玩家及时处理重要邮件和附件。

---

### Q3：附件领取失败怎么办？

**A**：需检查服务器端的物品发放逻辑是否正常。

---

### Q4：如何在HUD中显示邮件红点？

**A**：使用 ```HasNewMail()``` 接口判断是否显示红点。

---

### Q5：可以修改邮件的保存天数吗？

**A**：一般邮件默认保存30天，抽奖邮件默认保存100天，该值由后端配置决定。前端可以在 ```UGCMailboxComponent``` 中设置过期时间计算逻辑，但实际的过期清理由服务端控制。

---

### Q6：邮件支持哪些附件类型？

**A**：附件系统支持游戏内的虚拟物品。附件数据格式为 ```{ [物品ID] = 数量 }```，具体支持的物品类型由项目的道具系统决定。

---

### Q7：自定义UI后如何替换默认界面？

**A**：在 ```UGCMailboxComponent``` 中修改 ```MailUIPath``` 属性，指向自定义UI蓝图路径即可。

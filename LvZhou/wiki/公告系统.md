# 公告系统

公告系统提供了一套服务端异步获取最新公告的能力，开发者可以在服务端拉取最新的公告列表，用于在游戏内展示公告内容、实现滚动通知等场景。

## 核心功能

- 异步获取最新的 5 条公告数据
- 返回结构化的公告信息（标题、内容、发布时间、是否置顶）
- 基于 `PromiseFuture` 的异步回调机制，支持成功/失败处理

## 接口说明

### `UGCAnnouncementSystem.GetLatestAnnouncements()`

发起异步请求，获取最新的 5 条公告。

| 配置项   | 说明                                                              |
| -------- | ----------------------------------------------------------------- |
| 生效范围 | 服务器（仅服务端可调用）                                          |
| 返回值   | `PromiseFuture` 异步对象                                          |
| 重复调用 | 若上一次请求未完成，返回上一次的`PromiseFuture`，不会重复发起请求 |

### 返回数据结构

成功回调中通过 `PromiseFuture:Get()` 获取到的 `Announcements` 是一个 Lua 数组，每个元素包含以下字段：

| 字段          | 类型    | 说明         |
| ------------- | ------- | ------------ |
| `Title`       | string  | 公告标题     |
| `Content`     | string  | 公告正文内容 |
| `PublishTime` | number  | 发布时间戳   |
| `bTop`        | boolean | 是否置顶     |

## 使用示例

### 基础用法：获取公告列表

```lua
-- 仅在服务端调用
local PF = UGCAnnouncementSystem.GetLatestAnnouncements()

PF:Then(function(PromiseFuture)
    local Announcements = PromiseFuture:Get()
    for i, Announcement in ipairs(Announcements) do
        ugcprint(string.format("[公告] %s - %s (置顶: %s)",
            Announcement.Title,
            Announcement.Content,
            tostring(Announcement.bTop)))
    end
end)

PF:Else(function(PromiseFuture)
    ugcprint("[UGCAnnouncementSystem.GetLatestAnnouncements] Failed, timeout")
end)
```

### 进阶用法：在服务端定时刷新公告并同步给客户端

```lua
local AnnouncementManager = {}

function AnnouncementManager:RefreshAnnouncements()
    -- 需要先判断是否在服务端
    if not UGCGameSystem.IsServer() then
        return
    end

    local PF = UGCAnnouncementSystem.GetLatestAnnouncements()

    PF:Then(function(PromiseFuture)
        local Announcements = PromiseFuture:Get()
        -- 在这里处理公告数据，例如筛选置顶公告
        for _, Announcement in ipairs(Announcements) do
            if Announcement.bTop then
                -- 处理置顶公告，比如同步给客户端展示
                ugcprint("[公告-置顶] " .. Announcement.Title)
            end
        end
    end)

    PF:Else(function(PromiseFuture)
        ugcprint("[AnnouncementManager] 获取公告失败，请检查网络状态")
    end)
end

return AnnouncementManager
```

## 注意事项

1. **仅服务端可用**：`GetLatestAnnouncements` 只能在服务端调用，客户端调用会直接返回一个已取消的 `PromiseFuture`
2. **防重复请求**：如果上一次请求还没有完成，再次调用会返回上一次的 `PromiseFuture`，不会重复发送网络请求
3. **异步回调**：`PromiseFuture:Get()` 只能在 `Then` 回调函数中使用，不能在回调外直接调用
4. **失败处理**：建议始终通过 `Else` 设置失败回调，避免请求超时后无任何提示

# 1.37 Release Notes

关于版本功能使用中发现及反馈的bug修复安排，可前往 [bug修复计划公示表](https://docs.qq.com/sheet/DSUFnT1BQWGpHYWNN?tab=b5fzcz) 中查看了解。

<br>

## 1.37.10.16420 版本说明

### 编辑器

**bug Fixes**

- 修复进行多模式配置时，新增模式ID均为0的问题
- 修复切换场景后出现弹窗报错的问题
- 修复死亡盒子未打开时，玩家会自动拾取盒子内物品的问题
- 修复死亡盒子列表中，可装备物品的装备按钮无效的问题
- 修复设置视角的相关API失效的问题
- 修复怪物模板中“匪帮护卫”、“花魁仙”、“匪帮帮主”、“匪帮小弟”、“魁仙舞姬”无血条显示的问题
- 修复冲锋技能UI显示异常的问题
- 修复技能模板中“火焰环绕”和“魔术黏弹”缺失音效配置的问题
- 修复怪物模板中“电锯老大”的血条位置显示异常的问题
- 修复望远镜瞄准视角显示异常的问题
- 修复打开功能演示模板工程时，提示缺失部分UI和武器资源的问题
- 修复创建工程页面的筛选条件异常作用于打开工程页面的问题
- 修复装备背包时枪械异常穿模的问题
- 修复背包使用过的物品在杀进程重进后状态还原的问题

## 1.37.10.16414 版本说明

### 编辑器

**新功能**

- 新增邮件模板，方便开发者为玩家分发奖励、公告等信息
- 新增新手引导模板，支持在玩法内快速加入新手引导内容
- 新增局内添加好友功能，满足玩家在对局内快速添加其他玩家的需求
- 新增智能过滤插件，帮助开发者高效检索所需资源
- 新增玩法内公告功能，支持在玩法通过接口获取公告内容
- 新增更新与公告的提示功能，编辑器使用期间将弹出版本更新或官方公告的通知

**功能更新**

【物资系统】

**物品编辑器**

- 优化物品拾取优先级的逻辑
- 物品实例化数据支持
- 支持自定义物品拾取列表的显示效果
- 支持物品属性显示数值
- 支持构造物品的配件Attach信息
- 模板新增支持武器类型
- 支持配置更多样式的掉落特效
- 新增物品模板资源：

|类型|模板名称|
|:-:|:-:|
|俯视角武器|地狱火箭筒|
|俯视角武器|勇士霰弹枪|

|特殊武器|造冰枪|
|技能物品|小鸡魔法棒|
|技能物品|烟花堆|
|近战武器|拳击手套|

**背包系统**

- 优化背包UI组件

【技能系统】

**技能编辑器**

- 扇形目标选取器新增反选半径
- 技能加载/卸载支持局内数据持久化
- 支持配置不同玩家模型作为施法者进行预览
- 支持将双持武器用作技能预览的武器蓝图
- 支持下拉框选动画自定义Slot
- 状态互斥系统支持打断换弹
- 优化挥拳模板

|:-:|-|

# FUGCCustomDamageNumberItemParams

自定义伤害数字单元

## Variables

| Name | Type | Description |
|------|------|-------------|
| ImagePath | FString | 图片路径 |
| Text | FString | 文本，只支持数字和符号，图片路径为空时才有效 |
| ImageScaleX | float | 图片X轴缩放比例 |
| ImageScaleY | float | 图片Y轴缩放比例 |

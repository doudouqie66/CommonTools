# FWidgetTransform

Describes the standard transformation of a widget

## Variables

| Name | Type | Description |
|------|------|-------------|
| Translation | FVector2D | The amount to translate the widget in slate units |
| Scale | FVector2D | The scale to apply to the widget |
| Shear | FVector2D | The amount to shear the widget in slate units |
| Angle | float | The angle in degrees to rotate |

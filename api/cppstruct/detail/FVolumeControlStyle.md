# FVolumeControlStyle

Represents the appearance of an SVolumeControl

## Variables

| Name | Type | Description |
|------|------|-------------|
| SliderStyle | FSliderStyle | The style of the volume control slider |
| HighVolumeImage | FSlateBrush | Image to use when the volume is set to high |
| MidVolumeImage | FSlateBrush | Image to use when the volume is set to mid-range |
| LowVolumeImage | FSlateBrush | Image to use when the volume is set to low |
| NoVolumeImage | FSlateBrush | Image to use when the volume is set to off |
| MutedImage | FSlateBrush | Image to use when the volume is muted |

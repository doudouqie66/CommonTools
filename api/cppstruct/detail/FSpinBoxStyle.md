# FSpinBoxStyle

Represents the appearance of an SSpinBox

## Variables

| Name | Type | Description |
|------|------|-------------|
| BackgroundBrush | FSlateBrush | Brush used to draw the background of the spinbox |
| HoveredBackgroundBrush | FSlateBrush | Brush used to draw the background of the spinbox when it's hovered over |
| ActiveFillBrush | FSlateBrush | Brush used to fill the spinbox when it's active |
| InactiveFillBrush | FSlateBrush | Brush used to fill the spinbox when it's inactive |
| ArrowsImage | FSlateBrush | Image used to draw the spinbox arrows |
| ForegroundColor | FSlateColor | Color used to draw the spinbox foreground elements |
| TextPadding | FMargin | Padding to add around the spinbox and its text |

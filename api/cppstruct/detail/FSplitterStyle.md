# FSplitterStyle

Represents the appearance of an SSplitter

## Variables

| Name | Type | Description |
|------|------|-------------|
| HandleNormalBrush | FSlateBrush | Brush used to draw the handle in its normal state |
| HandleHighlightBrush | FSlateBrush | Brush used to draw the handle in its highlight state |

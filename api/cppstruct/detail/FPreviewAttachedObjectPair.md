# FPreviewAttachedObjectPair

Preview items that are attached to the skeleton

## Variables

| Name | Type | Description |
|------|------|-------------|
| AttachedObject | TSoftObjectPtr < UObject > | the object to be attached |
| Object_DEPRECATED | UObject * |  |
| AttachedTo | FName | The name of the attach point of the Object (for example a bone or socket name) |

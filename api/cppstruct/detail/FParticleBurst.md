# FParticleBurst

## Variables

| Name | Type | Description |
|------|------|-------------|
| Count | int32 | The number of particles to burst |
| CountLow | int32 | If >= 0, use as a range [CountLow..Count] |
| Time | float | The time at which to burst them (0..1: emitter lifetime) |

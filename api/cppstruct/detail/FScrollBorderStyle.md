# FScrollBorderStyle

Represents the appearance of an FScrollBorderStyle

## Variables

| Name | Type | Description |
|------|------|-------------|
| TopShadowBrush | FSlateBrush | Brush used to draw the top shadow of a scrollborder |
| BottomShadowBrush | FSlateBrush | Brush used to draw the bottom shadow of a scrollborder |
